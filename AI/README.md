# AI Specification Documentation

Welcome. This `/AI` folder is the single source of truth for the development of the FarmSetu Farm-to-Consumer Marketplace. 
It bridges the gap between the initial Figma-generated frontend and a robust, production-ready full-stack application.

## How to use this folder

1. **Start Here**: Read `PRD.md` to understand the product, goals, and user roles.
2. **Understand the Rules**: Read `DevelopmentRules.md`. You must follow these strictly while coding.
3. **Review Architecture**: Read `Architecture.md` and `TechStack.md`.
4. **Check the UI Mapping**: Read `UIContext.md` to see how the Figma design maps to the backend APIs.
5. **Database & API**: Refer to `DataSchema.md` and `API.md` when building backend features.
6. **Follow the Roadmap**: Look at `Phases.md` for the step-by-step implementation plan.
